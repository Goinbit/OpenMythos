# 深度外推决定性实验(预注册设计)

**日期:** 2026-10-27 · **地位:** 项目可行性门实验——其结果决定是否值得投入 GPU 做规模化验证
**假设来源:** Recurrent-Depth Transformer 核心卖点:推理时增加循环深度 T = 更多串行计算 = 更强推理

---

## 1. 任务(串行深度试金石)

| 任务 | 实例格式(文本) | 深度需求来源 | 难度分桶 |
|---|---|---|---|
| 进位加法 | `1234+567=` → 答案反序 `1080`→`0801` + EOS | 进位链 = 串行依赖链 | 操作数位数 1-4 |
| 奇偶校验 | `011010…=` → `0/1` + EOS | 逐位异或扫描,深度 Ω(n) | 位长 8/16/24/32 |

小词表(13:数字 0-9 + `+` `=` EOS),参数集中在循环块(embedding <0.1%),使循环深度成为主导变量。

## 2. 训练与扫描矩阵

- 模型:dim512 / n_heads8 / expert512(≈12M,vocab 13),从头训练,固定 `max_loop_iters=4`
- 训练损失:仅答案位(mask 复用 `compute_loss` 的 per-token mask);贪心解码(argmax)评测
- **主扫描(H1)**:训练@4,推理 n_loops ∈ {2, 4, 8, 16, 32},N=300 实例/桶
- **对照(H2)**:训练@16 的同任务模型,验证"训练期深度"本身是否买准确率

## 3. 预注册读数标准

| 读数 | 判定 | 后续动作 |
|---|---|---|
| 难桶 acc(16) − acc(4) ≥ +5pp | **正信号** | 论证 GPU 预算,1-3B 复现 |
| acc(8) ≥ acc(4) 且难桶持平 | 部分信号(优雅外推) | 加 loop-embedding 噪声变体复测 |
| 全曲线平坦或 8+ 恶化 | **负结果** | 架构假设在此训练范式下不成立;项目定格为教育性资产 |

## 4. 已知混杂(如实声明)

1. **loop-index 越界钳制**:训练@4 时 `loop_idx_table` 只有 4 行,loops>4 钳到末行——外推失败可能是索引编码而非深度不足;负结果时用 H2 与噪声变体区分
2. **ACT 加权混合**:h_out 是逐循环加权和(halting 概率权重),可能稀释深度效应;此前实测全部位置饱和于末循环,行为≈"末循环主导"
3. 单层循环块(prelude/coda 各 1):有效深度 = T×1;若信号为正再加深验证倍增关系

## 5. 成本

单任务单档 ≈ 12M 参数、4k steps(batch 64, seq ≤48)≈ 30-45 分钟 MPS;Phase A(add-4 + parity-4)+ 扫描 ≈ 2h 本地。
